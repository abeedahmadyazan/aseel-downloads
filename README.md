# تنزيل أسيل

برنامج أسيل للمبيعات والمحاسبة — نسخة Windows.

[تحميل أسيل 1.0.7](https://github.com/abeedahmadyazan/aseel-downloads/releases/download/v1.0.7/Aseel-Setup-1.0.7.exe)

بعد التثبيت، أرسل رمز الجهاز الظاهر داخل البرنامج إلى مزود نسختك للحصول على ملف التفعيل. التفعيل دائم ومخصص لجهاز واحد، ويعمل دون إنترنت.

هذا المستودع مخصص لملفات التثبيت فقط. لا يحتوي على المصدر الأصلي أو أداة إصدار التراخيص أو مفاتيحها.
